# Minimal OEM stock reference

Ten unmodified configuration/build-property files from the preserved ODM
extraction of **CPH2745_16.0.10.601(EX01), OnePlus 15 / SM8850**. This is not a
live phone dump. OEM configuration content retains its original provenance and
is not claimed as original project-authored code.

The reference is 677,196 bytes. `op15/reference.json` pins each file's SHA256.
Git attributes disable text/newline conversion for these bytes. Do not edit,
format or translate the OEM files. No firmware images, libraries, calibration
partitions, private device serials, account data or photos are bundled.

Use `GUIDE.md` to import these files into ignored `op15/inputs/` and reproduce
the tests/build. Matching them is not proof of whole-firmware compatibility,
runtime activation or improved photos. A different live build needs a new
reviewed reference and candidate, not relaxed guards.
